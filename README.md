# Система управления заказами

Проект разделён на три файла:
- `index.html` — HTML-разметка
- `style.css` — стили оформления
- `script.js` — клиентская логика

## Структура

- Верхнее меню
- Панель инструментов
- Панель фильтров
- Таблица заказов
- Вкладки с содержимым (вкладка 1 заполнена, остальные пустые)
- Нижняя панель формы

## Запуск

Откройте `index.html` в любом современном браузере.
